## 本次分级：哪些先不动

- **验收收尾，不当作小问题注销**：validation 缺少“数据库未新增”验证；config 缺少“DATABASE 精确等于传入路径”验证。使用通用验证策略改进后，冻结版本跑完整新批次，不修改 Oracle 或挑最好结果。
- **可暂缓，放第 2 期**：ordering 取证效率低；`search_code` 是字面搜索却被当作正则。先明确语义和上下文策略，不直接增加工具上限。
- **可暂缓**：工具额度将尽时是否提供受预算约束的最终作答阶段。当前超限停止属于预期保护，未产出答案仍计任务失败。
- **可暂缓**：格式恢复四次带来的额外成本；login 从过期 Cookie 推断执行 `session.clear()` 的不可靠表述。先保留案例，不继续为单题堆提示词。
- **可暂缓的整理**：命名、类型、重复落盘、Trace 内嵌对象转换等；按对应模块下一次修改时一起整理。
- **扩大能力前必须处理**：路径/符号链接边界、敏感信息、实际执行超时；引入写入时还要补审批绑定、隔离副本、拒绝越权。当前白名单 pytest 会执行仓库 Python 代码并产生临时文件，“只读 Agent”不等于操作系统级只读沙箱。
- **下一轮正式对比前补**：保存不可变的运行配置、模型请求参数、提示词/源码/任务版本，不能只依赖事后读取配置。
