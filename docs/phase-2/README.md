## 1. 本期目标

用有限调用和上下文找到真正相关的证据。分清：搜索是找出现位置，索引是预先整理文件/符号位置，上下文选择是挑有限、带来源的片段交给模型。

已有 search_code 是区分大小写的字面匹配，不是正则或语义搜索。最新 ordering 已找到关键查询却继续调查，因此增加检索工具不保证修好它；要分别衡量取证、推理、及时作答、协议有效性。

继续 CLI、只读分析、现有模型适配器和 Loop。新增轻量 Python AST 符号索引、简单排序、片段去重和预算。首版每任务构建内存索引，不 import/执行被分析模块，不做持久缓存。

暂不做向量数据库、Embedding、模型摘要记忆、写入工具、审批 API、多 Agent 或 SWE-bench。格式恢复沿用现状，独立记录失败，不与检索实验同时调参。

## 2. 模块边界（已实现主体）

```text
repopilot/retrieval/
  schema.py           # 文件/符号/命中片段模型
  index.py            # 安全遍历与 AST 提取
  search.py           # 名称/路径检索排序
  context.py          # 去重、片段选择、字符预算
tests/retrieval/
  test_index.py
  test_search.py
  test_context.py
```

保留现有 `repopilot/tools/search.py` 和 `tests/tools/test_search.py`。新算法不依赖模型 SDK，后续通过 tools/base.py 的注册方式接薄工具包装，输出继续使用 ToolResult。

索引根只能是准备好的被测工作区，不是 RepoPilot 根目录。Oracle、参考补丁、密钥、运行产物不能进入索引。新扫描器读取前验证每个候选最终路径，过滤敏感/忽略目录；已有路径缺口不能直接复制过来。
