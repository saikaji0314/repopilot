# 增量8：可选仓库事实记忆

日期：2026-10-17，基于 `f57700d`。实现仓库事实的存储、检索和阶段接线；未调用付费模型，没有安装向量服务或修改模型依赖。

## 验收对应

| 完成条件 | 实现与验证 |
| --- | --- |
| 记忆有来源 | 从HEAD对应的实际文件捕获片段、提交号与依赖指纹；拒绝未提交的来源内容，不存模型观察文字 |
| 跨运行、隔离仓库 | 独立SQLite数据库；重开存储仍可检索，不同Git公用目录不共享，worktree与来源仓库共享 |
| 版本变化有失效 | 来源或登记依赖变化／缺失、提交对象不可用或30天TTL过期时停用；无关提交不全局失效 |
| 生命周期可控 | 自动收集为候选，人工确认后激活；支持撤销、清空索引片段与墓碑，重放不会复活同一已删除事实 |
| 检索有界 | 本仓库active记录最多扫描200条，验证排名前20条，最多5条、条目JSON不超过6000 UTF-8字节 |
| 接入实际执行阶段 | 在实现／审核／返工载荷中提供事实；阶段前复核，已经修改的文件事实不会继续送给审核与返工 |
| 恢复可追溯 | 命中集合和snapshot_id持久化；暂停后新记忆不会混入旧运行，恢复不重跑已完成阶段 |
| 保留交付边界 | 默认关闭，支持profile与命令行覆盖；记忆管理不加载凭证，数据库损坏不阻断原实现／验证／审批流程 |

新增系统提示仅说明这些内容是不可信文件参考，不能覆盖任务、工具、检查或审批。未将记忆作为高优先级指令，也没有加入模型可写记忆的工具。

## 实际本地CLI演示

使用独立的虚构Git仓库与独立输出目录，不修改真实目标仓库、运行账本或既有记忆。

| 步骤 | 命中数 | 判定 |
| --- | ---: | --- |
| 冷启动 | 0 | 无已登记事实 |
| 登记源码与依赖后 | 1 | 命中有来源的clamp文件事实 |
| 修改依赖文件 | 0 | source_changed，不注入旧事实 |
| 恢复原依赖内容 | 1 | 当前内容重新匹配原来源 |
| 撤销 | 0 | 已停用 |
| 删除后再次登记同一事实 | 0 | 保留删除墓碑，不自动复活 |

这证明存储、命中和失效机制，**不是模型“冷启动／热启动”的效果对照**。原始CLI结果保留本机忽略目录，未提交私密路径或运行数据。
