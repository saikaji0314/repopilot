## 环境失败与复核

初次定向测试遇到沙箱默认临时目录权限问题，改为仓库内专用临时目录后29项通过。第一轮全量为318通过、6失败、5跳过，涉及默认临时目录权限及本地 Git 子进程访问；调整测试执行环境后，本地 Git 项通过，但4项旧题集仍失败，全量为320通过、4失败、5跳过。

进一步确认：旧题集在不含 `.git` 的复制目录执行 `git apply`。当该临时目录位于本仓库内部时，Git 向上发现主仓库，缺陷注入未按预期生效。为该轮临时目录设置 `GIT_CEILING_DIRECTORIES` 后，4项单独复核全部通过，最终全量也全部通过。旧版生产实现没有为测试环境修改；全部失败输出在本地保留。

本机最终测试采用以下环境安排，路径每轮唯一，均在工作区内：

```powershell
$testRoot = Join-Path (Get-Location) ('.local/tmp/test-' + [guid]::NewGuid().ToString('N'))
New-Item -ItemType Directory -Path $testRoot | Out-Null
$env:TEMP = $testRoot
$env:TMP = $testRoot
$env:GIT_CEILING_DIRECTORIES = $testRoot
.\.venv\Scripts\python.exe -m pytest -q -rs -p no:cacheprovider --basetemp (Join-Path $testRoot 'pytest')
```

上面的环境变量仅用于该测试终端；新终端使用原配置。测试过程未访问真实模型或远端 GitHub。
