# RepoPilot 0.1.0rc1

这是实验性预发行的本地候选，远端发布尚未执行。适用场景是可信代码仓库中的明确小任务；复杂任务修复能力仍受调查收敛与上下文限制。

## 包含的能力

- 本地需求或 Issue 接入，独立 Git worktree、实现、自检、独立验证、审核及有限返工。
- SQLite 阶段持久化和显式恢复，累计预算不随重启清零；人工批准绑定具体提交，交付终点为草稿 PR／MR。
- 本机受控执行或可选 Docker 执行，限定范围的通用文本工具；可选有来源与失效判断的仓库事实记忆。
- DeepSeek 默认配置，Qwen／兼容接口与 Claude 原生适配入口；GitHub 与 GitLab 平台适配和轮询监听。
- 安装后的用户数据目录、自定义环境文件、离线 HTML 报告；MIT 许可与源码包。

## 验证层级

GitHub 有历史真实 Issue→草稿 PR 演示；GitLab、Qwen、Claude 只有离线适配验证。安装目录与持久化的原始候选验证见[增量20](../VALIDATION.md#历史机制验收)；当前代码回归533项通过、12项跳过，固定镜像Docker及诊断专项32项通过。

后续加入阶段内工具观察工作集与保守的会话压缩，以及显式冻结源码书签的记忆评测入口。跨运行记忆仍默认关闭；模型调用、上下文及预算的默认限额没有随评测profile扩大。见[上下文](CONTEXT.md)及[记忆](MEMORY.md)。

[增量22](../../evals/reports/context-memory-20261019.md)保留全部13次尝试及追加协议：首轮同代码／同配置关闭记忆五题官方4/5、完整复核审核1/5；修正组及记忆结果单列，不选择最好结果拼接。19254仍未解决，且修正组两次遇到未查明的Docker执行错误；已补充安全诊断，不宣称故障已修复。它不是完整SWE-bench Lite、留出集或生产成功率。

## 安装与升级

候选文件为 `repopilot-0.1.0rc1-py3-none-any.whl`、`repopilot-0.1.0rc1.tar.gz` 和 `SHA256SUMS`。按[安装指南](INSTALL.md)创建虚拟环境、配置模型密钥并登记可信检查；Docker与项目依赖需另行准备。

现有源码运行继续使用原 `.env` 和 `.local/runtime`。从源码改为wheel时，请显式指向原配置及运行目录；不自动迁移SQLite、预算或worktree。wheel仅注册新版`repopilot`命令，历史基线从完整源码运行。

## 已知限制

- 仅Windows＋CPython3.12完成原生安装验证；其他宿主平台只覆盖目录规则单元测试。
- 默认本机检查具有操作者权限，仅用于可信仓库；Docker尚无工作卷磁盘配额或硬杀残留自动回收，不是microVM。
- GitLab真实鉴权、实例差异及交付未验证；多平台监听去重键不含host/provider，避免在同一监听器登记同名同号的跨平台任务。
- 复杂任务可能过度调查、超出上下文／调用限制，模型审核不能代替人工判断。
- 不自动合并、发布目标软件或部署。候选包验收不等于远端Release已发布。
