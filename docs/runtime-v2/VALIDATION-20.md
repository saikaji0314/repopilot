# 增量20：0.1.0rc1 本地预发行候选

日期：2026-10-18。基于平台接入提交 `0d60153` 继续，按[预发行验收边界](PRE-RELEASE.md)处理安装与集成。候选版本为 `0.1.0rc1`；此前 `1.0.0` 是源码开发元数据，本轮改用明确的预发行版本。许可证采用维护者选择的 MIT。

## 变化

- 新增 `core/paths.py` 统一配置与运行目录选择。源码运行保留根 `.env` 和 `.local/runtime`；wheel 使用启动目录 `.env` 与用户可写数据目录，支持 `REPOPILOT_ENV_FILE / REPOPILOT_RUNTIME_DIR`。模型、GitHub、GitLab、监听 worker 共用环境文件规则，不修改已存在的数据、预算或 worktree 路径。
- CLI 增加 `--version`，帮助展示实际默认输出目录。保留 `--output` 覆盖。wheel 不再注册需要源码配置与题集的 `run-baseline`，历史代码和源码调用方式保留。
- 元数据声明候选版本和 MIT，构建包附带许可。源码包包含公开文档、示例、约束与测试，排除 Git 元数据和 Python 缓存；wheel 保留 CSS 与容器 worker。
- 提供[安装与升级说明](INSTALL.md)，包括模型／平台配置、默认路径、显式覆盖、已有运行目录的继续使用，以及实验性效果边界。

## 保留的边界

这是一份可安装的实验性候选，尚未发布到远端。GitLab、Qwen、Claude 没有新增真实 API 验证；GitHub 真实交付为历史记录。复杂任务复测仍见[增量18](VALIDATION-18.md)：两题在两轮均未解决，失败的收敛提示已撤回，不在本轮继续调参。

原生安装只实测 Windows＋CPython 3.12；Linux／macOS 目录规则有单元测试，不能视为整个平台已经实测。运行仍要求可信仓库与已准备的 Git／检查环境；Docker 是可选执行后端，不提供 microVM 或磁盘配额。多平台监听去重键仍未包含 host／provider，不应在同一监听器登记可能同名同号的跨平台任务。自动合并和部署仍不属于交付范围。
