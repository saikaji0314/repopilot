## 按失败证据修复Harness

原 `repository_session` 只在阶段正常退出时导出，受控超限会直接清理容器，丢弃已经完成的编辑。现改为：可写阶段捕获RunLimit后，先停止容器并执行原有完整归档、路径、体积和宿主快照校验；合法部分改动导入worktree，记录 `sandbox_partial_checkpoint`，然后重新抛出超限。

非法产物仍拒绝导入，失败状态和in_flight仍保留，恢复仍须显式核对；不自动提交、批准或发布。其他异常、硬杀与Docker失联不保证保存未导出的编辑。该修复没有回写历史运行，也没有再次调用收费模型。
